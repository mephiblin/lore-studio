대본 또는 로어 글의 문장별 사실 주장을 추출하고 다음을 검사한다.
- 잠긴 사실과 충돌
- 출처 없는 고유명사·정밀 수치
- 네임스페이스 혼입
- 추론을 확정 사실로 표현
- 폐기 설정 사용
- 떠오름→죽음, 떠남→실종, 누락→은폐, 이동→비밀 회수, 증상→변이처럼 근거보다 강해진 동사·수식어
- ‘가능성’, ‘시사’, ‘~라기보다’를 붙여 새 가설을 우회적으로 도입하거나 공식 기록 주체의 갈무리·축소·은폐 의도를 부여한 문장
- 장면·문서 시점 이후의 사실 또는 화자/작성자가 접근할 수 없는 비공개 자료 사용
- 제공되지 않은 직접 인용, 기록 번호, 날짜, 직함, 출처 생성
- 새로 선택하지 않은 근거나 장면 이후의 정보로 분량 미달을 채운 문장
- 계획에서 고정한 반복 신호의 소리·밝기·지속·발원을 재등장할 때 바꾼 문장
- `symbolic_explanation=forbidden`인 결과물에서 상징의 뜻을 직접 정의한 문장
수정은 직접 덮어쓰지 말고 문제 문장, 이유, 권장 조치를 구조화해 반환한다.
