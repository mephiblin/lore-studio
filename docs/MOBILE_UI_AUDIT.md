# 모바일 UI 점검표와 2026-08-10 감사 기록

이 문서는 `390×844`, `360×844` 기준에서 Lore Studio의 하단 메뉴, 작업면, 스크롤 소유권, 상태 전환과 터치 동선을 반복 검사하기 위한 실행 표입니다. 일반 변경 안전성은 [`CHANGE_SAFETY_CHECKLIST.md`](CHANGE_SAFETY_CHECKLIST.md), 페이지별 기준은 [`UI_PAGE_CONTRACT.md`](UI_PAGE_CONTRACT.md)를 함께 적용합니다.

## 1. 모바일 정보구조 명제

- 전역 하단 메뉴는 장소 전환만 담당하고, 현재 페이지의 본문과 핵심 동작을 가리지 않는다.
- 다열 데스크톱 패널을 세로로 단순히 쌓지 않는다. 목록과 상세가 동시에 주인공이 될 수 없으면 `목록 → 상세 → 목록` 전환으로 분리한다.
- 모바일 읽기·편집 본문은 브라우저 문서가 세로 스크롤을 소유한다. 내부 `overflow` 영역은 modal·제한된 선택 목록처럼 소유권이 분명한 경우에만 사용한다.
- 로어북은 원고 관리 표가 아니라 책장이다. 모바일 `/lorebook`은 제목·분량·날짜를 훑는 목차, `/lorebook?entry=<id>`는 하나의 글을 읽는 상세다.

## 2. 반복 점검 리스트

### 공통 화면·터치

- [ ] `390×844`, `360×844` 모두에서 `documentElement.scrollWidth <= innerWidth`이다.
- [ ] 하단 메뉴의 위치·높이가 변하지 않고, 본문 끝에 그 높이 이상의 안전 여백이 있다.
- [ ] 시작 화면의 핵심 제목·선택·CTA가 하단 메뉴 뒤로 가려지 않는다.
- [ ] 터치를 시작한 자식 영역이 스크롤되지 않는 상태일 때 부모 문서의 세로 스크롤을 차단하지 않는다.
- [ ] 긴 한국어 제목, 선택 문장, 태그, 버튼 문구가 부모 폭을 늘리지 않는다.
- [ ] 입력·버튼을 focus/자동 스크롤한 후 하단 메뉴가 터치 좌표를 가로채지 않는다.
- [ ] tooltip·modal·AI 검토 패널이 viewport 밖으로 나가거나 다른 패널 뒤에 숨지 않는다.
- [ ] 모든 icon-only 조작에 접근 가능한 이름과 현재 상태가 있다.

### 상단 command bar

- [ ] 프로젝트 선택과 `+새 프로젝트`가 360px에서도 한 행을 유지한다.
- [ ] 세계관 자료의 다섯 로컬 탭이 페이지 가로 넘침을 만들지 않는다.
- [ ] 글 만들기 9단계는 360px에서 5+4 두 행 안에 보이고, 가로 스크롤을 요구하지 않는다.
- [ ] 원고 작업 3단계는 한 행을 유지하고 본문보다 큰 소개 패널처럼 보이지 않는다.

### 페이지별

- [ ] `/`: 프로젝트 생성 modal이 하단 메뉴 위에 완전히 들어오고, 커버 카드 동작을 hover 없이 사용할 수 있다.
- [ ] `/editor`: 자료 목록을 고르면 본문으로 이동하고, 본문 위 스와이프가 페이지 스크롤을 진행한다.
- [ ] `/editor`: 긴 AI 선택 문장이 편집기·페이지 폭을 늘리지 않고, 수정·반영 버튼이 하단 메뉴 위에서 터치된다.
- [ ] `/playbook`: 자료 카드 목록·`자료 더 보기`·`이전/계속` 바·하단 메뉴가 서로 겹치지 않는다.
- [ ] `/documents`: `원고 도구 보기 ↔ 초안으로 돌아가기`가 왕복하고, 단계 전환 후 새 작업면 상단을 보여 준다.
- [ ] `/lorebook`: query 없이 진입하면 목차만, `?entry=<id>`로 진입하면 읽기 화면만 보인다.
- [ ] `/lorebook`: 목차의 글 선택, 브라우저 직접 URL, `← 목차로`, 삭제 후 목차 복귀가 모두 안전하다.
- [ ] `/lorebook`: 네 테마가 목차와 읽기 본문에 이어지고, 읽기 상태에서 공통 `글 편집`·본문 대비를 유지한다.

## 4. 수정 후 검증 요약

- 360px command bar: 글 만들기 `292→184px`, 원고 작업 `186→134px`, 로어북 목차 `171→122px`.
- 로어북 목차는 제목·문자 수·날짜의 터치 리스트로 교체했고, 읽기 화면은 y=18에서 `목차로`로 시작하며 설정 command bar를 숨겼다.
- 네 로어북 테마는 목차 색·질감과 읽기 시트에 계속 적용되며 본문·내보내기 데이터를 바꾸지 않는다.
- Chromium 필수 상태: 다섯 route, 세계관 자료 본문 스크롤, AI 수정/작성, 글 만들기 고정 footer, 원고 도구, 로어북 목차→읽기→목차, 네 테마, 11,969자 긴 본문.

이 감사의 `VERIFIED`는 위 route·상태·viewport와 기록한 검사법 범위에만 해당합니다.
