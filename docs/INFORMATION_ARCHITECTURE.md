# Lore Studio 정보 구조

## 한 문장 구조

사용자는 **프로젝트를 선택하고 → 세계관 자료를 정리하고 → 글에 쓸 자료와 방향을 선택하고 → 만들어진 원고를 편집한다.**

내부 구현 명칭은 API와 개발 문서에 남길 수 있지만, 기본 화면은 사용자가 하려는 작업의 이름을 사용한다.

## 전역 메뉴

| 메뉴 | 경로 | 사용자의 질문 | 포함하는 것 |
| --- | --- | --- | --- |
| 프로젝트 | `/` | 어느 세계에서 작업할까? | 프로젝트 선택·생성, 모델 연결 상태 |
| 세계관 자료 | `/editor` | 이 세계에는 무엇이 있나? | 인물·장소·사건·기타 자료, 자료 간 연결, 글의 방향 규칙 |
| 글 만들기 | `/playbook` | 무엇을 어떤 방향으로 쓸까? | 주제·배경·요소·갈등 선택, 방향 규칙, 글 형태, 근거, 문단 구성 |
| 원고 편집 | `/documents` | 만들어진 글을 어떻게 완성할까? | 문단 편집, 근거 확인, 변경안 승인, 새 설정 후보 승인 |

## 핵심 객체와 경계

- **프로젝트**: 하나의 세계관과 그 자료·원고를 격리하는 최상위 범위다. 모든 주요 화면에서 선택하고 새로 만들 수 있다.
- **세계관 자료(Concept Page)**: 인물·장소·사건 등 세계를 설명하는 자유 본문이다. 자유 본문이 기본이며 구조화 필드는 보조 정보다.
- **자료 연결(Concept Relation)**: 두 자료의 관계다. 화면에는 ID가 아니라 두 자료의 이름과 자연어 관계를 표시한다.
- **글의 방향 규칙(Direction Card)**: 세계의 사실이 아니라 글을 전개하는 원칙이다. 선택한 원고 생성에만 영향을 주며 정식 설정을 만들거나 바꾸지 않는다.
- **집필 방식(Writing Recipe)**: 정보를 풀어낼 문단 순서다. 방향 규칙과 별개다.
- **결과물(Output Profile)**: 세계관 설명 글, 소설 장면 등 출력 형식이다. 집필 방식과 별개다.
- **글 만들기 기록(Playbook Session)**: 선택 자료, 방향 규칙, 집필 방식, 결과물, 시점·시제, 분량, seed를 저장해 생성 과정을 재현한다.
- **원고(Document)와 문단(LoreBlock)**: 생성 결과다. 원고에서 발견된 새 설정은 후보일 뿐이며 사용자가 승인하기 전까지 정식 설정이 아니다.

## 화면 원칙

1. 글 만들기는 `주제 → 배경 → 주요 요소 → 갈등·변수 → 전개 방향 → 글 형태 → 확인·작성`의 순서형 질문으로 구성한다. 한 화면에는 현재 질문의 선택 동작만 표시한다.
2. 주제는 한 개가 필수이고 나머지 자료 역할은 선택 사항이다. 선택하지 않은 단계는 명시적인 건너뛰기 문구로 넘긴다.
3. 앞 단계에서 역할이 정해진 자료는 뒤 역할 후보에서 제외하고, 완료한 단계는 진행 표시나 최종 검토에서 다시 열 수 있다.
4. 최종 검토 뒤에는 `근거 확인 → 문단 구성 → 원고 작성` 순서를 UI와 비활성 상태로 드러낸다.
5. UUID, enum, 모델 별칭, namespace, 토큰 같은 내부 정보는 기본 정보 계층에서 숨기거나 자연어로 번역한다.
6. 관계, 방향 규칙, 새 설정 후보는 각각 무엇을 바꾸는지와 무엇을 바꾸지 않는지 가까운 위치에서 설명한다.
7. 프로젝트 선택은 화면을 이동해도 유지한다.
