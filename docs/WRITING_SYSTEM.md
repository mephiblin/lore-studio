# 작문 시스템 명세

## 1. 네 층의 분리

Lore Studio의 작문 품질은 다음 네 층을 분리하는 데서 시작한다.

```text
Concept Pages     무엇에 대해 쓸 것인가
Direction Cards   이번 글이 무엇을 향할 것인가
Writing Recipe    정보를 어떤 작문 방식으로 풀 것인가
Output Profile    최종 매체에 맞게 어떻게 표현할 것인가
```

하나의 자연어 프롬프트로 이 네 역할을 뭉치면 재사용과 수정이 어려워지고, 어떤 선택이 결과에 영향을 주었는지 알 수 없게 된다.

## 2. 집필 레시피는 목차가 아니다

나쁜 레시피:

```text
1. 기원
2. 외형
3. 능력
4. 부작용
5. 결말
```

이 구조는 특정 소재에만 적용된다.

좋은 레시피:

```text
넓은 맥락에서 독자를 위치시킨다.
대상으로 시야를 좁힌다.
확정 사실을 배치한다.
통념으로 설명되지 않는 예외를 추가한다.
추상 설명 뒤에 구체적 사례를 둔다.
사실의 세계관적 의미와 파급을 확대한다.
충분히 설명하되 근본 원인은 완전히 닫지 않는다.
```

이는 유물, 행성, 종족, 전쟁, 기술, 종교, 기관 등 다양한 소재에 재사용할 수 있다.

## 3. 수사적 이동(Rhetorical Move)

레시피는 문단이 수행하는 역할을 Move로 정의한다.

| Move | 기능 |
|---|---|
| `ORIENT` | 시대·장소·사회·우주적 맥락에 독자를 위치시킨다. |
| `NARROW` | 넓은 배경에서 이번 대상으로 초점을 좁힌다. |
| `ANCHOR` | 확정된 핵심 사실이나 관찰을 제시한다. |
| `COMPLICATE` | 기존 설명으로 풀리지 않는 예외·모순·대가를 추가한다. |
| `COMPARE` | 알려진 것과 비교해 낯선 대상을 이해시킨다. |
| `EXEMPLIFY` | 추상 규칙을 사건·사물·개인의 결과로 구체화한다. |
| `ESCALATE` | 위험·규모·시간·사회적 파급을 확대한다. |
| `INTERPRET` | 사실이 세계관에서 갖는 의미를 해석한다. |
| `WITHHOLD` | 근거 없는 해답을 피하고 의도적 미지를 보존한다. |
| `TURN` | 앞서 형성한 기대나 의미를 뒤집는다. |
| `STING` | 짧고 강한 문장으로 절이나 글을 닫는다. |

레시피는 모든 Move를 고정 순서로 강제하지 않는다. 필수 Move, 선택 Move, 조건부 삽입 규칙, 금지되는 반복을 정의한다.

## 4. 기본 집필 레시피

### 4.1 소설 장면형

인물의 지각과 행동을 중심으로 하나의 시간 연속 장면을 만든다.

```text
상황 진입 → 욕구·목표 → 장애 → 선택 → 결과·새 상태
```

### 4.2 극화형 로어

이미 알려진 장소·사건·괴물의 흔적에서 출발해, 현재 모습이 만들어진 과거를 짧은 서사로 복원한다.

```text
현재의 인상 → 이전의 정상 상태 → 최초의 균열
→ 돌이킬 수 없는 사건 → 알려진 현재로 합류 → 여운
```

중심은 장기 성장 서사가 아니라 로어 대상의 변화다.

### 4.3 점층적 설정 풀이형

설정 설명 자체를 정보 공개의 이야기로 만든다.

```text
넓은 맥락 → 대상에 수렴 → 알려진 사실 → 예외·모순
→ 구체적 현상·사례 → 의미와 파급 확대 → 미지 보존
```

헤일로 디바이스 글에서 가져오는 것은 유물별 항목이나 단계 구조가 아니라 다음 작문 원리다.

- 넓은 역사에서 개별 대상으로 서서히 줌인
- 기관·기록·관찰의 제한된 지식으로 세계 내부의 실재감을 형성
- 추상적 설명 뒤에 물리적·인간적 결과를 배치
- 확정 사실과 가설을 다른 어조로 구분
- 긴 설명 뒤에 짧은 결정문을 두어 리듬 형성
- 설명을 충분히 하되 근본 원인은 닫지 않음

### 4.4 인-유니버스 문서형

세계 안의 특정 작성자와 목적을 가진 문서로 쓴다.

```text
문서 목적 → 관찰·증거 → 기관의 해석 → 누락·검열·편견
→ 독자가 추론할 수 있는 균열
```

보고서, 재판 기록, 군사 브리핑, 종교 문헌, 탐사 일지 등에 사용한다.

## 5. Direction Card의 역할

방향성 카드는 작문 레시피와 다르다.

- “점층적 설정 풀이형으로 써라”는 레시피다.
- “해결책이 사회적 의존으로 변하게 하라”는 방향성 카드다.
- “기억을 먹는 항로와 수도회를 사용하라”는 컨셉 선택이다.
- “영상 내레이션으로 6분 분량”은 출력 프로필과 분량 설정이다.

카드는 다음 구조를 가질 수 있다.

```json
{
  "must_include": ["초기 효능은 실제로 유용하다"],
  "avoid": ["효능이 처음부터 거짓이었다는 반전"],
  "sequence": ["도입", "성공", "의존", "대가", "정착"],
  "ending_preference": "완전한 해결보다 지속되는 구조"
}
```

사용자 원문은 항상 보존하고, 구조화 결과는 보조 해석으로 취급한다.

## 6. Output Profile

같은 소재와 레시피도 매체에 따라 다르게 실현한다.

### 설정 글

- 중간~긴 문장
- 높은 정보 밀도
- 문단 단위 논리 전개
- 근거는 내부 메타데이터 또는 각주

### 영상 내레이션

- 발화하기 쉬운 문장
- 한두 문장마다 시각 비트
- 괄호·긴 삽입절 최소화
- 생성 후 TTS 실측 길이로 조정

### 소설 장면

- 장면 내부 시간의 연속성
- 인물 시점과 감각
- 설명보다 행동·대화 비중 증가

## 7. 작문 감사

### Canon Auditor

- 출처 없는 고유 사실
- 다른 네임스페이스의 혼입
- 확정 사실과 추론 혼동
- 시대·관계 충돌
- 폐기 설정 사용

### Discourse Auditor

- 추상 설명만 연속됨
- 같은 결론 반복
- 규모 변화 없이 평면적으로 나열
- 사례가 설명을 증명하지 않음
- 모든 문단에 억지 반전
- 결말이 앞 내용을 단순 요약

### Style Auditor

- 상투어·접속사 반복
- 문장 길이 단조로움
- 추상명사 과다
- 선택한 서술자 위치 이탈
- 참고 표본 문구의 과도한 유사성

## 8. 참고 표본 분석

참고 글은 `DISCOURSE_REFERENCE`로 저장한다. 사실 검색에는 사용하지 않고 다음만 추출한다.

- 문단별 Move
- 스케일 변화: 우주→사회→대상→개인 등
- 확실성 변화: 확정→보고→논쟁→미지
- 정보 밀도
- 문장 길이 패턴
- 전환 방식
- 문단 종결 기능

분석 결과를 사용자가 검토한 뒤 집필 레시피와 Voice Profile로 승격한다.
