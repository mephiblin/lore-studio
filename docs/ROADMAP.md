# 구현 로드맵

## Foundation

- 저장소, Compose, DB, API, 기본 UI
- OpenAI 호환 모델 연결
- 프로젝트와 컨셉 페이지 CRUD

## Daily-use MVP

- 노션형 페이지 템플릿과 관계
- 프로젝트 집필 지침 덱
- 플레이북 선택·무작위 풀
- 구성안 승인과 문서 생성
- 문단 부분 재작성

## Evidence and Search

- 전문 검색과 BGE-M3
- 문단별 근거 표시
- 사실·담화 감사
- 네임스페이스와 연속성 검증

## Lore Loop

- 새 컨셉 후보 추출
- 사용자 승인과 승격
- 후속 글과 다른 관점 생성
- 반복·유사 구성 감지

## Reference Analyzer

- 참고 글의 Move·스케일·확실성 분석
- 레시피와 Voice Profile 후보 생성
- 원문 모방 억제

## Multimodal

- PDF·웹·영상 전사 수집
- 이미지 캡션과 검색
- 영상 비트·TTS·ComfyUI 연동
