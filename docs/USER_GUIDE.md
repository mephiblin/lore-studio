# 사용자 가이드

## 1. 프로젝트 선택

`프로젝트`에서 작업할 세계를 선택합니다. 이름과 한 줄 설명만으로 새 프로젝트를 만들 수 있으며, 프로젝트마다 세계관 자료와 원고가 분리됩니다. 선택한 프로젝트는 다른 화면으로 이동해도 유지됩니다.

## 2. 세계관 자료 정리

`세계관 자료`에서 인물·장소·사건·유물 같은 자료를 만듭니다. 본문에 먼저 자유롭게 기록하고, 필요할 때 태그·한 줄 요약·확정된 사실·열린 질문·금지 변경을 덧붙입니다.

`연결된 자료`에서는 대상 자료의 이름과 관계를 골라 연결합니다. 화면에는 내부 ID 대신 자료 이름이 표시됩니다.

`글의 방향 규칙`은 세계관 설정이 아닙니다. “선의의 결과가 새 문제를 만든다”처럼 원고가 사실을 어떤 순서와 태도로 다룰지 정하는 전개 원칙입니다. `AI로 세부 규칙 정리`는 사용자가 쓴 원문을 바꾸지 않고 생성에 쓸 목표·순서·필수 요소·피할 전개를 제안하며, 확인 후 저장할 때만 적용됩니다.

## 3. 글 만들기

`글 만들기`는 한 번에 한 질문만 보여 주는 순서형 화면입니다.

1. `주제`에서 원고의 중심 자료 한 개를 선택합니다. 이 단계만 필수입니다.
2. `배경`에서 장소·시대·상황 자료를 고르거나 선택 없이 넘어갑니다.
3. `주요 요소`에서 함께 다룰 인물·사건·유물을 복수 선택하거나 넘어갑니다.
4. `갈등·변수`에서 긴장과 변화를 만들 자료를 복수 선택하거나 넘어갑니다.
5. `전개 방향`에서 원하는 글의 방향 규칙을 고릅니다. 선택하지 않아도 됩니다.
6. `글 형태`에서 집필 방식, 결과물, 시점·시제, 분량과 자료 반영 범위를 정합니다.
7. `확인·작성`에서 전체 선택을 검토합니다. 수정 버튼으로 원하는 단계에 돌아갈 수 있습니다.
8. `사용할 설정 확인`에서 AI가 사실로 사용할 내용·답을 정하지 않을 내용·변경 금지 설정을 확인합니다.
9. `글의 흐름 만들기`에서 각 문단이 어떤 순서로 무엇을 설명할지 편집합니다. `?` 도움말에서 ‘배경 설명’, ‘주제로 초점 이동’ 같은 문단 방식의 뜻을 바로 확인할 수 있습니다.
10. `원고 작성`으로 실제 Writer 모델을 호출합니다. 완성되면 새 원고가 선택된 `원고 편집` 화면으로 자동 이동합니다.

앞 단계에서 선택한 자료는 뒤 역할의 후보에서 빠집니다. 따라서 같은 자료가 주제와 배경처럼 서로 다른 역할에 중복 지정되지 않습니다.

선택 자료, 방향 규칙, 집필 방식, 결과물, 시점·시제, 길이, seed는 글 만들기 기록에 저장됩니다. 같은 기록을 통해 어떤 조건으로 생성했는지 추적할 수 있습니다.

## 4. 원고 편집과 설정 승인

`원고 편집`은 두 단계입니다.

1. `초안 편집`에서 문단별 내용을 수정하고 각 문단이 참고한 세계관 자료를 이름으로 확인합니다. `부분 재작성`은 원문을 바로 덮지 않고 비교할 변경안을 만든 뒤 사용자가 적용하거나 폐기하게 합니다.
2. `완성본`에서 `전체 글 다듬기`를 실행합니다. 최신 초안 전체와 글 만들기에서 정한 `이번 원고에만 추가할 지시`, 집필 방식, 결과물 종류, 시점·시제, 분량, 자료 범위, 자유도, 자세함, 미스터리 보존 값을 Writer에게 다시 전달합니다. Writer는 새 사실을 추가하지 않고 연결·중복·문단 호흡을 한 번 더 다듬습니다.

초안 문단과 완성본은 별도로 보존됩니다. 완성본을 만든 뒤 초안을 수정하면 화면에 이전 초안 기준이라는 경고가 표시되며, 최신 초안으로 다시 다듬을 수 있습니다. 완성본 화면에서 내보내면 완성본을, 초안 화면에서 내보내면 현재 초안을 사용합니다. 모바일에서도 두 단계를 전환하고 완성본을 편집·저장할 수 있습니다.

원고에서 추출한 새 설정은 자동으로 세계관에 들어가지 않습니다. `이번 글만`, `설정 초안`, `정식 설정` 중 사용자가 직접 결정합니다. Markdown, HTML, JSON 내보내기도 이 화면에서 할 수 있습니다.

참고 글과 이미지 분석 결과 역시 자동으로 정식 설정이 되지 않습니다.
