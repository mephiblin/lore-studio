# 사용자 가이드

## 1. 프로젝트 선택

`프로젝트`에서 작업할 세계를 선택합니다. 이름과 한 줄 설명만으로 새 프로젝트를 만들 수 있으며, 프로젝트마다 세계관 자료와 원고가 분리됩니다. 선택한 프로젝트는 다른 화면으로 이동해도 유지됩니다.

## 2. 세계관 자료 정리

`세계관 자료`에서 이 프로젝트의 설정 자료를 만듭니다. `+ 새 자료`에서는 이름과 자료 종류만 정하며, 새 항목은 원고가 참고할 세계관 설정으로 안전하게 시작합니다. 새 프로젝트에는 인물·장소·사건·유물·자유 페이지가 시작용 `자료 종류`로 들어오지만, 다른 프로젝트와 공유되는 고정 프리셋은 아닙니다. `자료 종류` 탭의 카드에서 이름을 바꾸거나 세력·마법 체계·생물종처럼 이 세계에 맞는 종류를 추가할 수 있습니다. 별도의 분류 기준을 작성하지 않고, 알아보기 쉬운 이름 자체를 분류 기준으로 사용합니다.

종류를 삭제하려면 그 종류를 쓰는 자료를 먼저 다른 종류로 옮겨야 하며, 종류 이름을 바꿔도 연결된 자료 본문은 바뀌지 않습니다. 자료 본문은 여전히 중심이며, 필요할 때 태그·한 줄 요약·원고 작성 경계를 덧붙입니다.

본문 일부를 드래그하면 툴바의 `AI 수정`이 활성화됩니다. 다듬기·축약·확장·명확화·설정 충돌 완화 중 하나를 고르고 추가 지시를 적으면, AI는 전체 본문에서 선택부가 맡는 역할과 앞뒤 연결 조건을 먼저 파악한 뒤 선택한 부분의 대체문만 제안합니다. `더 자세히 (약 2배)`는 원문의 사실 범위 안에서 원인·작동 과정·감각·구체적 결과를 보강하며, 원문 길이에 따라 계산된 최소 확장 길이를 사용합니다. 근거가 부족하면 새 사실로 분량을 채우지 않고 경고를 남깁니다. 제안은 기존 문장과 비교한 뒤 `본문에 반영`해야 편집기에 들어오며, 이후에도 `변경 저장` 전까지는 저장되지 않습니다.

`AI 작성`은 자료 본문의 전체 초안, 현재 커서 위치에 넣을 내용, 기존 본문에 이을 내용을 제안합니다. 작성 지시·분량·이번 호출에서 참고할 자료를 선택할 수 있습니다. 연결된 자료는 처음에 선택되어 있지만 자유롭게 바꿀 수 있고, 이 선택은 이번 작성에만 사용되므로 자료 사이의 영구 연결을 추가하거나 삭제하지 않습니다. 영감·문체 참고 자료는 분위기와 승인된 구성 분석에만 사용하며 그 자료의 사실이나 고유명사를 현재 프로젝트 설정으로 가져오지 않습니다. AI가 낸 결과는 항상 검토할 제안이며 자동으로 설정이나 정식 설정이 되지 않습니다.

`원고 작성 경계`는 원고에서 참으로 유지할 `유지할 사실`, 아직 답이나 정체를 밝히지 않을 `공개 유보`, 발생시키거나 뒤집으면 안 되는 `금지된 변경·전개`로 나뉩니다. `본문에서 AI 제안`은 현재 편집 중인 본문을 읽고 각 항목과 근거 구절을 제안합니다. 제안은 자동 저장되지 않으며, 사용자가 항목을 고르고 입력한 뒤 `변경 저장`을 눌러야 반영됩니다.

`연결된 자료`에서는 대상 자료의 이름과 관계를 골라 연결합니다. 화면에는 내부 ID 대신 자료 이름이 표시됩니다.

`자료 종류`, `집필 지침`, `전개 방식`의 새 항목 생성과 수정은 목록 카드를 늘리지 않고 `AI 작성`과 같은 팝업 작업면에서 진행합니다. 팝업의 본문만 스크롤되고 취소·저장 버튼은 항상 아래에 남으며, 바깥 영역이나 닫기 버튼, Escape로 닫을 수 있습니다. 집필 지침 생성 창에는 소설·수필·보고서용 시작 프리셋이 있으며, 선택한 내용은 입력란에 복사될 뿐 저장 전 자유롭게 바꿀 수 있습니다.

`집필 지침`은 현재 프로젝트의 글에서 반복해 지킬 강조점과 금지 원칙입니다. “제도의 효능과 대가를 함께 보여 준다”처럼 세계관 사실을 추가하지 않고 이번 원고의 초점을 정합니다. 새 지침 생성이나 기존 지침 수정을 열면 `세부 규칙 직접 작성` 전체가 처음부터 보이며, 지침 목표·전개 순서·반드시 포함·피할 전개·선호 결말을 바로 입력할 수 있습니다. `AI로 세부 규칙 정리`는 사용자가 쓴 원문을 바꾸지 않고 같은 구조를 제안하며, 확인 후 저장할 때만 적용됩니다.

`전개 방식`에서는 프로젝트와 관계없이 사용하는 공용 기본 방식을 항상 보여 줍니다. 세계관 설명뿐 아니라 `목표에서 결과로` 소설 구성, `경험에서 통찰로` 수필 구성, `질문에서 결론으로` 보고서 구성을 제공합니다. 공용 방식은 읽기 전용이며, 현재 프로젝트에 특별한 정보 전개 순서가 필요할 때만 전용 방식을 추가합니다. 카드에는 AI와 글의 흐름 단계가 실제로 지키는 문단 방식 순서를 그대로 표시합니다. 단계 목적은 선택한 문단 방식에서 자동으로 정해지므로 따로 작성하지 않으며, 방식별 차이는 이름·설명·구성 규칙·완성 후 확인 기준에 기록합니다. 이미 글 만들기 기록에서 사용한 전용 방식은 재현성을 위해 삭제할 수 없고, 수정하면 새 버전으로 저장됩니다. 문체 참고 자료에서 `구성·문체 분석` 결과를 승인한 경우에도 같은 목록의 프로젝트 전용 방식으로 확인할 수 있습니다.

`문체·필력`에서는 독자에게 남길 인상, 문장 호흡, 묘사·대화·비유·문단 원칙과 피할 표현을 프로필로 만듭니다. 모든 프로젝트에 `장면 중심 소설 문체 / 구체적 성찰 문체 / 근거 중심 보고서 문체`가 읽기 전용 기본값으로 보이며, 복제해 프로젝트용 검토본으로 바꿀 수 있습니다. 새 프로필은 `검토 중`으로 저장되며 `사용 가능으로 승인`한 뒤에만 글 만들기에서 선택할 수 있습니다. 직접 쓴 짧은 예시, 허가된 예시, 퍼블릭 도메인 예시는 생성 참고로 켤 수 있지만 `분석만 허용` 예시는 Writer에게 전달되지 않습니다. 승인된 프로필을 수정하면 과거 원고의 재현성을 보존한 새 검토 버전이 만들어집니다. 문체 참고 자료의 `구성·문체 분석`은 전개 방식만, 문체만, 둘 다를 독립 승인할 수 있으며 어떤 승인도 프로젝트 사실을 추가하지 않습니다.

## 3. 글 만들기

`글 만들기`는 한 번에 한 질문만 보여 주는 순서형 화면입니다.

현재 단계의 카드와 설정만 본문에서 스크롤되며, 하단 `이전 / 계속` 이동 바는 마지막 `확인·작성`까지 데스크톱 화면 아래와 모바일 전역 메뉴 바로 위에 고정됩니다.

1. `주제`에서 원고의 중심 자료 한 개를 선택합니다. 이 단계만 필수입니다.
2. `배경`에서 주제를 이해하는 데 필요한 자료를 고르거나 선택 없이 넘어갑니다.
3. `주요 요소`에서 함께 다룰 자료를 복수 선택하거나 넘어갑니다.
4. `갈등·변수`에서 긴장과 변화를 만들 자료를 복수 선택하거나 넘어갑니다.
5. `집필 지침`에서 현재 프로젝트의 강조점·금지 원칙을 고릅니다. 선택하지 않아도 됩니다.
6. `전개 방식`에서 공용 기본 방식 또는 현재 프로젝트에서 만든 정보 공개 순서 하나를 고릅니다. 카드에 번호로 표시된 문단 방식이 실제 글의 필수 전개 순서입니다. 프로젝트 전용 방식은 `세계관 자료 → 전개 방식`에서 만들고 수정합니다.
7. `문체·필력`에서 승인된 프로필 하나 또는 `모델 기본 문체`를 명시적으로 고릅니다. 선택하지 않은 상태를 숨은 프로필로 바꾸지 않습니다.
8. `결과물 형태`의 카드에서 세계관 설명·영상·소설 장면·수필·분석 보고서·세계 내부 문서 중 하나와 시점·시제·분량을 정합니다. `선택 자료 본문 반영`은 관련 자료를 자동으로 더 찾는 기능이 아니라 주제를 포함해 직접 고른 자료의 본문을 얼마나 넣을지 정합니다. 선택 자료가 없다면 자동으로 꺼집니다. 왼쪽 원고 견본은 `원고 설계 / 출력 설정`으로 나뉘어 주제·배경·주요 요소·갈등·변수·집필 지침·전개 방식·문체·필력과 현재 고르는 형식·시점·시제·분량을 한곳에서 보여 줍니다.
9. `확인·작성`은 주제와 소재, 집필 원칙, 전개·표현 설계를 하나의 원고 설계 카드 묶음으로 보여 줍니다. 자료의 유지 사실·공개 유보·금지 변경은 글의 흐름을 만들 때 자동으로 정리되므로 별도 `설정 경계 정리` 버튼은 두지 않습니다. 각 카드의 수정 버튼으로 원하는 선택 단계에 돌아갈 수 있습니다.
10. 같은 화면의 `글의 흐름 설계 → 초안 작성` 경로를 순서대로 진행합니다. 하단의 주 동작 버튼이 현재 해야 할 작업으로 바뀝니다.
11. `글의 흐름 만들기`가 끝나면 흐름 편집 카드가 바로 같은 화면에 열리고 그 위치로 이동합니다. 선택한 전개 방식이 소재에 맞는 문단 순서로 바뀐 결과를 편집할 수 있으며, 머리말에서 문단별 분량 합계가 결과물 형태에서 정한 목표 글자 수와 일치하는지 확인할 수 있습니다. `?` 도움말에서는 ‘맥락 열기’, ‘핵심 근거·장면’, ‘의미·분석’ 같은 범용 문단 방식의 뜻을 확인할 수 있습니다.
12. `초안 작성`으로 실제 Writer 모델을 호출합니다. 작성이 끝나면 새 초안이 선택된 `원고 작업` 화면으로 자동 이동합니다.

앞 단계에서 선택한 자료는 뒤 역할의 후보에서 빠집니다. 따라서 같은 자료가 주제와 배경처럼 서로 다른 역할에 중복 지정되지 않습니다.

선택 자료, 프로젝트 집필 지침, 선택한 전개 방식과 버전, 결과물 형태, 시점·시제, 길이, seed는 글 만들기 기록에 저장됩니다. 같은 기록을 통해 어떤 조건으로 생성했는지 추적할 수 있습니다.

문체 프로필을 선택한 경우 profile ID/version과 실제 사용한 짧은 예시 ID도 함께 기록됩니다.

## 4. 원고 작업과 로어북

`원고 작업`은 세 단계를 한 화면씩 진행합니다.

`초안 편집`의 `필력 점검`은 저장된 원고 해시와 선택 문체를 기준으로 반복·호흡·예시 과잉 유사성을 찾으며 자동 수정하지 않습니다. 항목별 수정안을 만든 뒤 기존 변경안 비교에서 적용하거나 폐기합니다. `완성 설정`에서는 전개 방식과 문체·필력 프로필을 포함한 설정을 이번 완성본에 맞게 바꿀 수 있습니다.

1. `초안 편집`에서 제목과 문단별 내용을 수정하고 각 문단이 참고한 세계관 자료를 이름으로 확인합니다. `+ 새 문단 추가`로 문단을 더하거나 필요 없는 문단을 삭제할 수 있습니다. 상단 `저장`은 제목·상태·모든 문단을 한 번에 저장하며, `저장하고 완성 설정으로 계속`을 누를 때도 변경 내용이 자동 저장됩니다. 저장하지 않은 상태는 초안 선택 옆의 `저장 안 됨`으로 표시됩니다. 오른쪽 `원고 도구`에서 재작성·문장 점검·설정 후보 중 필요한 기능 하나를 열 수 있으며, `부분 재작성`은 원문을 바로 덮지 않고 비교할 변경안을 만든 뒤 사용자가 적용하거나 폐기하게 합니다.
2. `완성 설정`은 왼쪽 완성본 견본과 오른쪽 선택 카드로 구성됩니다. 글 만들기 때 사용한 값을 초깃값으로 불러오며, 형식·시점·시제·분량을 고르면 견본이 즉시 바뀝니다. 추가 지시, 전개 방식, 문체·필력, 자료 범위, 자유도, 자세함, 미스터리 보존도 이번 완성본에 맞게 변경할 수 있습니다. 이 변경은 원래 글 만들기 기록을 덮어쓰지 않습니다.
3. `완성본 만들기`는 확정한 설정과 로어북 저장 위치만 최종 확인합니다. 항목마다 수정 버튼을 반복하지 않으며, 바꾸려면 하단 `완성 설정`으로 돌아갑니다. 실행하면 최신 초안 전체와 확정 설정을 실제 Writer에게 전달하며, Writer는 새 사실을 추가하지 않고 연결·중복·문단 호흡을 한 번 더 다듬습니다.

완성본은 초안 레코드 안에 섞이지 않고 별도 `로어북` 문서로 저장됩니다. 상단 `로어북`에서 완성된 글만 읽고 수정하고 Markdown·HTML·JSON으로 내보낼 수 있습니다. 로어북 글을 만든 뒤 출처 초안을 수정하면 이전 초안 기준이라는 경고가 표시되며, 원고 작업에서 최신 초안으로 다시 만들 수 있습니다.

로어북 상단 도구 영역 왼쪽의 네 원형 버튼으로 `노말 / 판타지아 / 메카니컬 / 어반 판타지` 열람 테마를 바꿀 수 있습니다. 판타지아는 밝은 양피지, 메카니컬은 미세한 배경 글리치가 있는 형광 녹색 CRT, 어반 판타지는 비 내린 도시의 남색 네온입니다. 선택은 현재 브라우저에만 기억되며 프로젝트 설정이나 글 내용, 내보낸 파일에는 들어가지 않습니다. 원 안의 번호와 선택 ring으로 현재 테마를 구분할 수 있습니다.

초안에서 추출한 설정 후보는 자동으로 세계관에 들어가지 않습니다. `이번 글만`, `설정 초안`, `정식 설정` 중 사용자가 직접 결정합니다. 초안은 Markdown으로, 로어북 완성본은 Markdown·HTML·JSON으로 내보낼 수 있습니다.
