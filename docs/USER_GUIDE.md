# 사용자 가이드

1. 작업대에서 Writer/Utility/Vision/Embedding이 `READY`인지 확인합니다.
2. 컨셉 아카이브에서 프로젝트를 만들고 자유 본문, 태그, 역할, namespace, 시대/연속성, 잠긴 사실·열린 질문·금지 변경을 저장합니다.
3. 관계/백링크를 연결하고 BGE-M3 재색인을 실행합니다.
4. 방향성 카드를 원문으로 작성합니다. Utility 구조화 제안은 검토 후에만 적용합니다.
5. 플레이북에서 소재 슬롯, 카드 여러 장, 레시피, 출력 프로필, 시점/시제, 길이/상세도/자료 범위/창작 자유도/미스터리 보존을 선택합니다. seed와 고정 선택으로 추첨을 재현합니다.
6. 컨텍스트 미리보기의 확정 사실, 열린 질문, 금지 변경, 참고 자료를 구분해 확인합니다.
7. 구성안 블록을 편집·정렬·복제·삭제·잠근 후 실제 Writer로 원고를 생성합니다.
8. 문서에서 LoreBlock 근거 칩과 Canon/Discourse/Style 감사를 확인합니다. 부분 재작성은 원문을 덮지 않고 Diff 제안으로 만들어 승인/폐기합니다.
9. 후보를 추출해 이번 글만 사용, 초안 승인, 정사 승인 중 선택합니다. 정사 승인은 두 단계 승격과 audit log를 남깁니다.
10. Markdown, HTML, JSON으로 내보냅니다.

참고 글은 `DISCOURSE_REFERENCE`로 저장해야 하며 분석된 구조만 레시피/Voice Profile 후보가 됩니다. 이미지 분석 결과도 자동 저장되지 않습니다.
