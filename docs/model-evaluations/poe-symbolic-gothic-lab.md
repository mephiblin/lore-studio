## 분석 범위

원문은 [Project Gutenberg 공개판](https://www.gutenberg.org/cache/epub/1064/pg1064-images.html)을 기준으로 확인했다. 작품은 3인칭 외부 화자가 인물의 내면에 밀착하기보다 공간과 집단 전체를 내려다보는 우화형 단편이다. 다만 완전히 투명한 카메라는 아니다. 화자는 방을 설명하기 직전 “먼저 방들에 관해 말하겠다”는 식으로 독자의 시선을 잠깐 지휘한다.

재사용할 핵심은 포의 고유 어휘를 흉내 내는 것이 아니라 다음 구조다.

1. 바깥의 위협과 닫힌 안쪽의 확신을 짧게 대조한다.
2. 사건보다 먼저 공간의 관람 순서를 설계한다. 꺾인 방 배치는 한 번에 하나만 보이게 하고, 후반의 추격은 같은 순서를 실제 동선으로 다시 사용한다.
3. 색은 독립적인 상징 표가 아니라 불빛·창·천·사람 얼굴의 물리적 효과로 작동한다. 마지막 방만 앞선 색 규칙을 깨뜨린다.
4. 같은 시계 소리가 음악과 춤을 반복해서 중단한다. 매회 달라지는 것은 소리가 아니라 그것을 부정하려는 군중의 반응이며, 자정의 긴 중단이 낯선 형상을 알아볼 시간을 만든다.
5. 개별 인물보다 군중을 하나의 몸과 꿈의 행렬처럼 다룬다. 장문의 누적 리듬은 운동을 밀고, 소리가 울리는 순간 짧은 정지가 호흡을 끊는다.
6. 상징의 뜻을 본문에서 해설하지 않는다. 공간의 순서, 반복, 회피와 마지막 물리적 소멸이 의미를 만든다.
7. 설정과 분위기에 많은 분량을 쓰고 실제 대치와 파국은 매우 짧게 압축한다. 결말에서는 시계와 불빛이 인간과 함께 꺼지고 추상 명사가 잠깐 행위 주체가 된다.

동쪽에서 서쪽으로 이어지는 일곱 방을 생애 단계로 읽는 해석은 널리 쓰이지만 원문이 확정한 정답은 아니다. [CliffsNotes 분석](https://www.cliffsnotes.com/literature/p/poes-short-stories/summary-and-analysis/the-masque-of-the-red-death)도 세부 색채 암호보다 폐쇄된 공간과 하나의 효과를 만드는 기능을 우선해서 설명한다. Lore Studio 카드에는 특정 상징 사전을 넣지 않고 `순서가 있는 공간 + 반복 신호 + 마지막 규칙 파괴`라는 생성 원리만 옮기는 편이 안전하다.

## OpenWebUI 비교 설계

포의 왕자·역병·가면무도회·일곱 색 방·흑단 시계·유명 문장은 사용하지 않았다. 회백항의 319년 동부 수문 재개방 의식이라는 합성 자료로 다음을 검사했다.

- 기존 `장면 소설가`: 인물 목표와 제한 시점을 중시하는 현재 카드
- 신규 `상징적 고딕 우화 작가`: 외부 3인칭, 공간 순례, 집단 운동, 반복 신호를 중시하는 LAB 후보
- 공통 소재: 청동 → 소금빛 유리 → 젖은 검은 돌의 세 갑문 단, 철거된 종탑 쪽에서 들리는 같은 종소리, 안전 선언과 물에 들어가지 않는 노
- 금지: 관련 없는 312년 자료 혼입, 현재까지 지속된다고 확인되지 않은 현상, 사망·실종·괴물·음모, 상징 직접 해설, 포 원전 복제

## 반복 결과

### 1차 — 카드 비교

새 후보는 기존 장면 카드보다 공간 순서와 종소리에 따른 군중 반응을 분명히 만들었다. 그러나 세 갑문을 설정집처럼 차례로 설명했고, 노동자 반점을 장식적 비유로 끌어왔으며 312년의 금속 맛이 319년에도 지속된다고 썼다.

### 2·3차 — 단일 카드 규칙 강화

관련 없는 반점은 제거됐지만 다음 오류가 반복됐다.

- 같은 종소리를 매번 더 길게·짧게·날카롭게 바꿈
- `수문은 도시의 호흡/숨통이다`라는 설명문형 도입
- 현재까지 지속된다고 확인되지 않은 금속 맛·광택 재사용
- 요청 범위 뒤의 관습이나 해설을 결말에 추가

OpenWebUI DB를 확인해 v1.3 시스템 프롬프트와 temperature 0.50이 실제 저장된 것도 검증했다. 따라서 import 누락이 아니라 Gemma가 긴 단일 카드에서 고딕 상투어를 명시 규칙보다 우선한 결과다.

### 4차 — 과도하게 엄격한 Planner 계약

네 문단의 사건과 문장을 거의 고정하자 정사·공간·동일 신호·결말 경계를 모두 지켰다. 대신 요청한 1,200자에서 488자로 줄었고 `정확히 한 번`, `아까와 똑같이` 같은 작업 지시가 문장에 드러났다.

### 5차 — 기능·글자 예산형 Planner 계약

문단별 기능과 200~300자 예산만 남긴 중간 계약이 가장 나았다.

- 통과: 외부 3인칭, 행동으로 드러나는 공간, 동일한 종소리 세 번, 웃음→동요→침묵의 변화, 상징 비해설, 관련 없는 자료 배제, 물리적 이미지 결말, 포 원전 비복제
- 미달: 목표 900~1,200자에 624자, `기분 나쁜 광채`, `무거운 침묵` 같은 범용 고딕 표현

원문 결과는 `poe-symbolic-gothic-gemma-results.json`부터 `-v5.json`까지 보존한다.

## Lore Studio 도입 판단

현재 `소설 장면` 카드의 단순 업그레이드로 합치면 안 된다. 기존 카드는 제한 시점의 인물 목표·방해·선택을 만드는 데 적합하지만, 이 형식은 외부 화자와 집단·공간을 주인공처럼 사용한다. 프로덕션 도입 전 다음처럼 분해하는 것이 적절하다.

- Output Profile 후보 `상징적 우화 단편`: 외부 3인칭, 집단 중심, 상징 비해설, 압축된 파국
- Writing Recipe 후보 `공간 순례에서 귀결로`: 바깥/안쪽 대조 → 순서 공간 → 동일 신호 반복 → 마지막 규칙 파괴 → 빠른 물리적 종결
- Voice Profile 후보 `의례적 고딕 이야기꾼`: 누적 문장과 짧은 정지, 제한적 의인화, 아름다움과 불길함의 충돌
- Sampling 후보값: temperature 0.50, top-p 0.84, top-k 28, frequency penalty 0.12, presence penalty 0.03
- Planner 필수 산출: 문단별 공간, 집단 상태, 반복 신호의 불변 속성, 마지막 이미지, 글자 예산
- 감사 규칙: 신호 속성 변화, 관련 없는 자료 혼입, 현재까지 지속되지 않은 현상, 상징 직접 해설, 원전 고유 장치 복제, 목표 글자 수 미달

결론은 `LAB 유지, 프로덕션 보류`다. 형식 자체는 기존 장면 소설과 구별할 가치가 충분하지만, Gemma 단독 시스템 카드만으로는 정사와 길이를 안정적으로 지키지 못했다. Lore Studio의 Planner와 길이 보정·Canon Auditor를 포함한 분해 버전을 만든 뒤 같은 fixture로 다시 통과시켜야 한다.
