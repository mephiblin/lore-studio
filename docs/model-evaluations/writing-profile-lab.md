# OpenWebUI 작가 프로필 분해 실험

실행일: 2026-08-11  
기준 모델: `gemma4-26b-heretic-mtp` (Gemma4 26B Heretic NVFP4+MTP)  
실행 경로: OpenWebUI `LAB Gemma4 · …` 워크스페이스 모델 → Docker 전용 vLLM proxy

## 목적

기존 Lore Studio 카드를 짧은 설명만 늘리는 방식으로 수정하지 않고, 먼저 완성 작가 역할의 상세 시스템 프롬프트를 만든 뒤 실제 결과에서 유효한 규칙과 실패 경계를 분리한다. 실험 대상은 세계관 설정집, 영상 로어, 장면 소설, 성찰 에세이, 분석 보고서, 세계 내부 기록, 자료 큐레이션·해설 7종이다.

상세 프롬프트와 합성 회백항 자료는 `writing-profile-lab.yaml`, 1·2차 원문 결과는 JSON 파일에 보관한다. OpenWebUI에는 같은 프롬프트의 Qwen/Gemma 변형 14개를 `LAB` 태그로 등록했다. 카드 품질 판단과 반복 수정은 사용자의 요청에 따라 Gemma4 26B를 기준으로 수행했다.

## 1차 관찰

- 형식 적응, 문장 호흡, 장르 구분은 전반적으로 성공했다.
- 자료의 의미 강도를 높이는 오류가 여러 장르에서 반복됐다.
  - 물고기가 수면 가까이 떠오름 → 죽음·폐사
  - 도시를 떠난 뒤 기록 없음 → 실종·행방불명
  - 발표문에 언급 없음 → 의도적 은폐
  - 상자 이동 → 은밀한 회수·격리
  - 회색 반점 → 생물학적 변화·변이
- 장면 소설은 사건 이튿날 장면에 7년 뒤 관습과 다른 사람의 기록을 가져왔다.
- 세계 내부 문서는 약제사 마라가 알 수 없는 이덴의 편지와 미래 정보를 포함했다.
- 자료 큐레이션은 제공된 직접 인용을 구분하지 못하고 해설의 확신이 원자료보다 강해졌다.

## 2차 조정과 결과

상세 프롬프트에 의미 강도 보존 쌍, 시점별 접근 가능한 자료, 직접 인용 경계를 추가했다. 분석 보고서의 최종 판정은 `신뢰도가 낮다`에서 `부분적으로만 설명한다`로 낮아졌고, 세계 내부 문서에서 미래 정보와 이덴의 편지는 제거됐다. 그러나 장면 소설과 에세이는 여전히 일부 접근 불가 자료를 사용했고, 몇몇 결과에는 죽음·은폐·생물학적 변화로 강화하는 문장이 남았다.

따라서 긴 시스템 프롬프트는 좋은 설계 원본이지만 단독 품질 보증 장치로는 부족하다고 판정했다. Lore Studio에는 다음처럼 분해했다.

1. Output Profile: 결과물의 매체·화자 범위·직접 인용·결말 형식
2. Writing Recipe: 정보 공개 순서와 블록별 접근 가능한 근거
3. Voice Profile: 문장 호흡·표현 원칙·피할 의미 강화
4. 공통 Planner/Writer/Finalizer/Canon Auditor: 시간·정보 접근과 의미 강도 보존
5. Sampling Profile: 의미 규칙과 분리된 런타임 확률 제어

## 도입 결과

- 결과물 형태 8종: 기존 7종 보강 + `자료 큐레이션·해설`
- 전개 방식 10종: 기존 9종 보강 + `발췌에서 종합 해설로`
- 문체·필력 8종: 기존 4종 보강 + 설정집·청취·기록자·전문 해설 4종
- 생성 성향 3종: 정밀·균형·표현 풍부
- 고급 override: temperature, top-p, top-k, frequency penalty, presence penalty
- 분량: 기존 한국어 목표 글자 수 계약 유지. 프로필별 `max_tokens`와 고정 글자 수 없음

이 실험은 공개 벤치마크 점수가 아니라 동일한 합성 자료를 실제 OpenWebUI 워크스페이스 모델에 입력해 얻은 원문 품질 비교다.

## Lore Studio 실경로 확인

배포된 Lore Studio의 Writer 역할을 `gemma4-26b-heretic-mtp`로 둔 뒤 `자료 큐레이션·해설` + `발췌에서 종합 해설로` + `친근한 전문 해설 문체` + `정밀` 조합을 실제로 실행했다. Planner는 5개 블록을 만들었고 Gemma Writer는 문서를 정상 생성했다. 생성 입력에는 `precise@1.0.0`과 실제 적용값(temperature 0.42 override, top-p 0.82, top-k 24 등)이 저장됐다.

이 경로에서도 미확정 자료를 다룰 때 “공식 기록이 갈무리하려 했다”, “단순 누락이라기보다 다른 상태의 가능성을 시사한다”처럼 의도와 가설을 완곡하게 덧붙이는 잔여 오류가 관찰됐다. 이에 큐레이션 프로필·레시피·Writer·Canon Auditor에 다음 회귀 경계를 추가했다.

- `가능성`, `시사`, `~라기보다`는 근거 없는 새 가설을 허용하는 장치가 아니다.
- 공식 발표와 기록 공백의 공존만으로 기록 주체의 갈무리·축소·은폐 의도를 부여하지 않는다.
- 해설은 기록된 차이·공백·확실성 수준을 설명하며, 숨은 원인을 새로 제안하지 않는다.

이 결과는 샘플링 값 전달과 프로필 분해가 정상 작동한다는 통합 확인인 동시에, 의미 충실도는 향후 Canon Auditor 회귀 평가에서 계속 추적해야 하는 품질 항목임을 보여 준다.
